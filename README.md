# PCR Timeline Shift

《公主連結 Re:Dive》補償刀時間軸轉換工具。

[**🔗 Live Demo**](https://anong0u0.github.io/PCR-TimeLineShift/)

## 功能

- **時間計算**：依據剩餘秒數自動平移時間軸，可用 +/−（按住連續）、滑桿或直接輸入秒數。
- **邏輯過濾**：自動隱藏超時動作及其子項目，結果下方顯示換算與隱藏的行數。
- **狀態保存**：自動紀錄輸入與設定（只存在目前的瀏覽器）。
- **記憶管理**：桌面版在左側、手機版在下方列出所有刀，一鍵切換；每一刀的「⋯」可改名、建立複本或刪除（刪除後可復原），也可以雙擊或按 F2 直接在列表裡改名、按 Delete 刪除。未命名的刀以第一行作為名稱。
- **貼上與圖片 OCR**：可按「貼上」、在頁面任意處 Ctrl+V，或上傳、拖曳截圖自動辨識文字；若目前的刀已有內容，會另存成新的一刀。
- **轉換選項**：隱藏<1秒軸、嚴格模式、換算註解時間、凸顯時間直接顯示在秒數下方，旁邊的 ⓘ 有說明。
- **摺疊**：設定區、原始軸、左側刀列表都可以摺疊，騰出空間看結果，下次開啟會記住。
- **UI**：桌面版左右對照，手機版以「原始軸／結果」分頁切換；深色模式、自動換行與文字大小（在「⋯」→ 顯示設定）可調。

## OCR 備註

- OCR 模型採用 [PaddleOCRv5](https://www.paddleocr.ai/main/version3.x/algorithm/PP-OCRv5/PP-OCRv5.html)，支援中、英、日文。
- 首次使用 OCR 需要下載模型檔(~85MiB)，下載速度與辨識速度會因設備而異。
